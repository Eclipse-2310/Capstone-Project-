Privacy Notice

Last Updated: October 2026

1. Academic Project Scope

This web application is built strictly as an educational Capstone Project for demonstration and viva evaluation. It is not a commercial enterprise or public e-commerce store.

2. Information We Store

The application stores minimal user-provided information required to demonstrate database relationships and user authentication:

  • Full Name (for customer profiling and order invoice generation)
  • Email Address (used as the unique account identifier)
  • Cryptographic Password Hash (generated via PBKDF2-HMAC-SHA256 with random salt; plaintext passwords are never saved)
  • Order History, Order Items, and Delivery Status milestones

3. Data Security & Storage

All data resides in a local SQLite database file. No personal data, tracking cookies, or browsing analytics are transmitted to third parties, advertising networks, or external cloud providers.

4. Cookies & Session Management

The application utilizes a single standard HTTP session cookie to maintain your logged-in session, active cart stack, and CSRF token. No tracking, cross-site, or advertising cookies are utilized.
